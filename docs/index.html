Bóveda de Conocimiento y Sistema Operativo Personal (Brain OS v1.6)

Cómo el CIOdD-UCR PDF Intelligence Pipeline sirve como el motor de ingesta fundamental para alimentar Bóvedas de Conocimiento y asistentes autónomos.

El Problema que Resuelve

En organizaciones científicas y equipos de investigación, la información crítica vive dispersa en PDFs estáticos, informes anuales y bases de datos tabulares. Los LLMs fallan cuando se les arrojan PDFs crudos porque sufren de alucinación de páginas, tablas rotas y pérdida de párrafos cortos.

La Solución Integrada: Pipeline V5.2 + Brain OS

El PDF Intelligence Pipeline extrae el contenido con cero pérdida y trazabilidad matemática (Layer 0), mientras que Brain OS estructura la memoria operativa, compila vistas interactivas en HTML/Markdown y permite a agentes inteligentes ejecutar flujos de trabajo autónomos sin requerir intervención humana constante.

Las 4 Capas Funcionales de la Bóveda de Conocimiento

Capa 0: Ingesta Cruda
PDF Intelligence V5.2

Extracción limpia, OCR adaptativo, bboxes, detección de tablas y generación de Parquet/JSONL.

Capa 1: Compilador
Markdown & HTML

Compilación de notas atómicas en Obsidian y generación de tableros interactivos para revisión.

Capa 2: Memoria
Daily Logs & Flush

Memoria de corto plazo (bitácoras diarias) sincronizada con la memoria de largo plazo (biblioteca de claims).

Capa 3: Agente Autónomo
Colaborador Operativo

Agentes RAG que consultan DuckDB y FAISS para responder con citas verificables de documento y página.

Evolución Histórica: De `pdf_to_rac_json.py` (V1.0) a V5.2

Análisis comparativo de los defectos sistemáticos resueltos en la transición hacia un pipeline de nivel de investigación científica.

Dimensión Técnica Versión 1.0 / 4.0 Original (`pdf_to_rac_json.py`) Versión Final 5.2 (`pdf_intelligence`)
Conservación de Texto Pérdida silenciosa: toda sección de < 60 palabras se descartaba por completo. Cero pérdida: secciones cortas se fusionan controladamente; chunk_coverage ≥ 0.995.
Trazabilidad de Páginas El solapamiento entre fragmentos etiquetaba falsamente la página del párrafo adyacente. page_start / page_end cubren exclusivamente las palabras propias (unique_words).
Encabezados y Secciones Cualquier línea en mayúsculas o con número inicial creaba una nueva "sección" (1.655 falsos positivos). Detector multicriterio (score ≥ 2.0) con descalificadores y degradación de cabeceras repetidas.
Detección de Tablas Generaba ~1 tabla por página clasificando prosa partida como rejillas numéricas. Clasificador heurístico (AdaptiveTableExtractor) que aísla prosa en tables_rejected.jsonl.
Limpieza de Bordes La limpieza de cabeceras borraba dígitos legítimos en el cuerpo del texto. Normalización a # y recorte exclusivo en las 3 líneas de los bordes (removed_edge_lines).
Páginas OCR Utilizaba bloques de layout nativos ignorando el texto extraído por Tesseract. Las páginas bajo OCR sustituyen y alimentan directamente el texto limpio y las secciones.
Metadatos y Auditoría Sin verificación criptográfica, sin esquemas Parquet ni base DuckDB. corpus.duckdb, índices TF-IDF y FAISS, manifest.json con SHA-256 e integrity_report.json.

Documentación Técnica de la Biblioteca y CLI

Guía de instalación rápida, uso en línea de comandos y estructura de módulos.

1. Instalación Rápida

# Clonar repositorio
git clone https://github.com/tu-usuario/pdf-to-rag-pipeline.git
cd pdf-to-rag-pipeline

# Instalar paquete en modo desarrollo
pip install -e .

# Dependencias opcionales de Embeddings y FAISS
pip install -e ".[embeddings]"

2. Ejecución desde CLI

# Procesar lote de PDFs
pdf-intelligence process --input ./data/pdfs --output ./data/pdf_intelligence

# Búsqueda léxica local ultrarrápida con TF-IDF
pdf-intelligence search "inteligencia artificial educación" --top-k 5

# Auditar reporte de integridad
pdf-intelligence audit --output ./data/pdf_intelligence

3. Uso en Python como Módulo

from pdf_intelligence import PipelineConfig, CorpusBuilder, LocalSearch

# Configurar pipeline
config = PipelineConfig(
    pdf_directory="./data/pdfs",
    output_directory="./data/pdf_intelligence",
    ocr_enabled=True,
    chunk_target_words=550
)

# Ejecutar consolidación completa
builder = CorpusBuilder(config)
builder.process()

# Búsqueda local sin APIs externas
searcher = LocalSearch("./data/pdf_intelligence")
results = searcher.search_tfidf("gobernanza de datos", top_k=3)
